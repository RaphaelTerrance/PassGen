🔑 **PassGen (by RTF)**

PassGen is a lightweight, fast, and secure ciphertext generator designed with simple ciphers.

🚀 **Features**

Ciphertexting: Stores your Pwds as ciphertext. (Within the best of my abilities.)

CLI Support: Quick command-line interface usage for automation or terminal lovers.

Lightweight & Fast: Zero heavy external dependencies.

📦 **Installation**

Clone the repo in VS Code(like everyone else. Don't be a niche autistic coder):

git clone https://github.com/RaphaelTerrance/PassGen.git

cd PassGen

Make sure to download colorama using

pip install colorama

💡 **Usage**

Run the script directly from your terminal:
python prgv2.py
